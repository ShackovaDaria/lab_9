# Домашнее задание к работе 9

## Условие задачи
Написать программу, выводящую на экран заданную геометрическую фигуру, нарисованную с помощью заданного с клавиатуры символа. Предусмотреть возможность изменения размеров фигуры путем задания ее размеров в количестве символов пользователем. Вариант 6: равнобедренный треугольник (заполнение - да, параметр - высота h).

## 1. Алгоритм и блок-схема

### Алгоритм
1. **Начало**.
2. Устанавливаем кодировку UTF-8 для корректного вывода.
3. Запускаем цикл (do-while) для возможности повторного рисования:
   - Запрашиваем у пользователя символ для рисования.
   - Запрашиваем высоту треугольника `h`.
   - Проверяем, что `h > 0`. Если нет — выводим ошибку.
   - Если высота корректна, запускаем внешний цикл `i` от 1 до `h` (строки):
     - Внутри печатаем пробелы (чтобы сдвинуть треугольник вправо).
     - Запускаем внутренний цикл `j` от 0 до `2*i - 1` (количество символов в строке).
     - Печатаем символ `sim`.
   - Спрашиваем, хочет ли пользователь продолжить. Если введен `0` — выходим из цикла.
4. **Конец**.

```c
#include <stdio.h>
#include <locale.h>

char get_symbol(char sim, int i, int j, int h);

int main() {
    int h, i, j;
    char sim, cont;
    setlocale(LC_ALL, ".UTF8");

    do {
        printf("Введите символ из которого будет строиться фигура: ");
        scanf(" %c", &sim);
        
        printf("Введите высоту: ");
        scanf("%d", &h);
        
        if (h <= 0) {
            printf("Ошибка: высота должна быть положительной\n");
        } else {
            printf("Фигура:\n");
            for (i = 1; i <= h; i++) {
                for (j = 0; j < 2 * h - 1; j++) {
                    printf("%c", get_symbol(sim, i, j, h));
                }
                printf("\n");
            }
        }
        
        printf("\nПродолжить ? <Да - введите любое число, Нет - введите 0>: ");
        scanf(" %c", &cont);
        
    } while (cont != '0');

    return 0;
}
char get_symbol(char sim, int i, int j, int h) {
    // i - текущая строка (от 1 до h)
    // j - текущая позиция в строке (от 0 до 2*h-2)
    
    int start_pos = h - i;
    int end_pos = h - i + 2 * i - 1;
    
    if (j >= start_pos && j < end_pos) {
        return sim;
    } else {
        return ' '; 
    }
}
```
