# Домашнее задание к работе 8

## Условие задачи
Вычислите с использованием цикла for значение ряда, для заданных пользователем значений a и n.
Формула: a * (a - n) * (a - 2n) * ... * (a - n^2)

## 1. Алгоритм и блок-схема

### Алгоритм
1. **Начало**.
2. Настраиваем кодировку (локаль UTF-8), чтобы русский текст в консоли отображался без ошибок.
3. Запрашиваем у пользователя два числа:
   - вещественное число `a`;
   - целое число `n` (при этом `n` должно быть больше или равно 0).
4. Проверяем введенные данные:
   - Если `n < 0`, выводим сообщение об ошибке «Ошибка: n должно быть неотрицательным».
   - В противном случае вызываем функцию `proizv`, передаем ей `a` и `n`, результат записываем в переменную `res` и выводим на экран с точностью до 6 знаков после запятой.
5. **Конец**.

**Часть 2: Функция для вычисления произведения (proizv)**
1. **Начало функции**: получаем параметры `a` и `n`.
2. Задаем начальное значение для накопления произведения: `res = 1.0`.
3. Запускаем цикл `for`, где переменная `k` изменяется от 0 до `n` включительно (на последнем шаге множитель будет равен `a - n * n`, что соответствует `a - n^2`).
4. В теле цикла умножаем текущее значение `res` на очередной множитель: `res = res * (a - k * n)`.
5. Возвращаем итоговое значение `res` в функцию `main`.
6. **Конец**.

## 2. Реализация программы

```c
#include <stdio.h>
#include <locale.h>

double proizv(double a, int n);

int main()
{
    double a, res;
    int n;

    setlocale(LC_ALL, ".UTF8");

    printf("Введите число a: ");
    scanf("%lf", &a);
    printf("Введите целое число n (n >= 0): ");
    scanf("%d", &n);

    if (n < 0)
    {
        printf("Ошибка: n должно быть неотрицательным\n");
    }
    else
    {
        res = proizv(a, n);
        printf("Значение выражения: %.6lf\n", res);
    }
    return 0;
}

double proizv(double a, int n)
{
    int k;
    double res = 1.0;

    // Цикл от 0 до n включительно
    for (k = 0; k <= n; k++)
    {
        res = res * (a - k * n);
    }
    return res;
}
```
